## Network access control and routing

The computer-networking report covers access control lists and their interaction with routing in a simulated network.

### Topics covered

- Defining ACL rules to permit or deny selected traffic.
- Using time ranges to apply rules during specified periods.
- Observing ICMP and TCP traffic through packet analysis.
- Examining how rule order affects the outcome.
- Combining ACL configuration with OSPF routing.

The report records the configuration and observation process. A useful public extension would pair the written analysis with a reproducible topology, sanitized device configurations, and expected connectivity checks.

**Available material** — A local course report. Configuration files and a packet-capture package have not been released.

## Spring dependency injection

A local JavaEE experiment text describes a registration workflow that passes data from a view to a controller and then to a DAO for persistence. It discusses Spring dependency injection and the separation of application layers.

The text includes template fields. A verified, standalone implementation and completed report remain to be established before presenting it as a finished experiment.
