The FX widget and YOLO experiment include public source directories. The T5 experiment lives in its own repository. The Java application pages currently document local projects whose source release is still being prepared. Each page explains the available materials and verification status.

The pet adoption application is a course project adapted from an existing codebase. Project descriptions preserve that context and distinguish implemented features from proposed improvements.
